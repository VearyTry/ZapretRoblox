# 🔗 Zapret-Roblox — что это такое и с чем это едят?

**Zapret-Roblox** — это форк проекта **[Zapret](https://github.com/flowseal/zapret-discord-youtube)**, в котором добавлен удобный `STARTME.bat`.


<img width="951" height="363" alt="изображение" src="https://github.com/user-attachments/assets/de66f04f-f7d3-4e80-b635-b4599dfefa02" />


### Этот файл делает всё за тебя:
устанавливает сервис Zapret, настраивает домены и параметры, а также управляет запуском и остановкой.

# 😼 Как запустить Zapret-Roblox

## Запуск
1. Открой папку с файлами.
2. Запусти `STARTME.bat`.
3. Разреши запуск от администратора.
4. В появившемся окне выбери **1** и Enter.

Ждём пару секунд и готово! 
Можно наслаждаться любимыми играми и сервисами без задержек и VPN. <3

---

## Остановка
1. Запусти `STARTME.bat` ещё раз.
2. Нажми **2** и Enter.

---

## Если не работает
- Запусти `STARTME.bat` от имени администратора
- Убедись, что файл `bin\winws.exe` есть
- Отключи брандмауэр
- Отключи антивирус
- Запусти пункт **2 (Stop)**, потом снова **1 (Start)**

---

## Важно
- Работает только на Windows
- Не удаляй файлы из папки
