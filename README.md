## 🚀 Как запустить

1. Скачай архив **`.zip`** с [последнего релиза](https://github.com/VearyTry/ZapretRoblox/releases/latest)
2. Распакуй в любую удобную папку
3. Запусти **`STARTME.bat`** → выбери пункт **1** → нажми **Enter**

Готово! Zapret для Roblox уже работает.

## ✨ Что умеет Zapret-Roblox

- Автоматический запуск всех нужных компонентов Zapret
- Простое меню для запуска / остановки
- Никаких сложных команд и ручной настройки
